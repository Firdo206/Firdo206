## 👨‍💻 Tentang Saya

Saya mahasiswa **Teknik Informatika semester 5 di Politeknik Negeri Jember** yang suka mengubah masalah sehari-hari menjadi aplikasi yang berguna. Mulai dari aplikasi laundry, pemesanan bus pariwisata, sampai sistem parkir pintar, semuanya berawal dari satu pertanyaan: *"Bagaimana ini bisa dibuat lebih mudah?"*

```yaml
nama      : Firdo

jurusan   : Teknik Informatika (Semester 5)
fokus     : Web • Mobile • IoT • Sistem Cerdas
sekarang  : Mengembangkan Sistem Parkir Pintar berbasis IoT dan Sistem Cerdas 🚗
```

- 🔭 Sedang mengembangkan **sistem parkir pintar berbasis IoT**
- 🌱 Terus memperdalam **Laravel, Flutter, dan Python**
- 👯 Terbuka untuk kolaborasi di proyek **IoT, Mobile (Flutter), dan Web (Laravel)**
- 🤝 Ingin belajar lebih dalam soal **integrasi IoT dengan web dan mobile**
- 💬 Tanya saya soal **Laravel, Flutter, MySQL, Java, dan Python**
- ⚡ Fun fact: proyek-proyek saya selalu berawal dari **masalah sehari-hari**
